# LynnaLab Controls
  * Ctrl-Z: Undo
  * Ctrl-Shift-Z: Redo
  * F1: Open help
  * F4: Toggle quickstart
  * F5: Build & run game (Shift+F5 to force rebuild)

If "Scroll To Zoom" is set in LynnaLab settings, you can use the scroll wheel to zoom into the minimap, scratchpad, etc. You can pan with middle-click + drag.

The ImGui framework which powers LynnaLab also has some built-in hotkeys. I don't know them all but...

  * Tab: Navigate to next element
  * Ctrl+Tab: Cycle between open windows

Controls for specific windows are documented on their respective help pages.
